# Комп'ютерний практикум №2 — «Об'єктно-орієнтований підхід до побудови імітаційних моделей дискретно-подійних систем»

Python 3.12, лише стандартна бібліотека (залежностей немає).

## Класи моделі

| Файл | Зміст |
|---|---|
| `element.py` | `Element` — базовий елемент: затримка, лічильник, маршрути `(елемент, ймовірність)` |
| `create.py` | `Create` — джерело вимог |
| `process.py` | `Process` — обслуговування кількома пристроями, черга, відмови, статистика |
| `dispose.py` | `Dispose` — вихід вимог із моделі |
| `model.py` | `Model` — алгоритм імітації за принципом найближчої події |
| `fun_rand.py` | генератори випадкових величин (exp, unif, norm) |
| `theory.py` | аналітичні формули M/M/c/K для верифікації |

## Завдання

Кожний скрипт запускається окремо, без аргументів (виконання 1–8 с):

| Скрипт | Завдання |
|---|---|
| `task1_single.py` | 1–2: один пристрій з чергою, середнє завантаження пристрою |
| `task3_chain.py` | 3–4: CREATE → PROCESS 1 → PROCESS 2 → PROCESS 3 → DESPOSE і верифікація (9 прогонів) |
| `task5_multichannel.py` | 5: кілька ідентичних пристроїв, порівняння з M/M/c/K |
| `task6_routing.py` | 6: вихід у кілька блоків і повернення в попередній, порівняння з мережею Джексона |

Результати відтворювані: у кожному прогоні генератор ініціалізується `fun_rand.seed(1)`,
тому вивід програм збігається з наведеним у звіті (`report/Звіт_КП2.docx`).
