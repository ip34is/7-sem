# Комп'ютерний практикум №4 — «Оцінка складності алгоритму імітації»

Python 3.12 + Matplotlib (лише для графіків). Залежності: `pip install -r requirements.txt`
(у проєкті вже є готове середовище `.venv`).

## Файли

| Файл | Зміст |
|---|---|
| `element.py`, `create.py`, `process.py`, `dispose.py`, `fun_rand.py` | класи універсального алгоритму з КП №3 без змін |
| `model.py` | алгоритм імітації з КП №3 + лічильник виконаних подій `events` |
| `networks.py` | мережі з N СМО: послідовна, дерево, віяло, з поверненням |
| `complexity.py` | вимірювання часу імітації, оцінка ν·T·k, графіки |
| `output/` | графіки `task2_chain.png`, `task4_branching.png` |
| `report/` | звіт `Звіт_КП4.docx` / `.pdf` |

## Завдання

Кожний скрипт запускається окремо, без аргументів:

| Скрипт | Завдання | Час роботи |
|---|---|---|
| `task1_chain.py` | 1: модель з N послідовних СМО (N задається на початку файлу), перевірка з M/M/1 | ~2 с |
| `task2_complexity.py` | 2–3: експериментальна і теоретична оцінка складності, N = 15, 30, 60, 120 | ~8 с |
| `task4_branching.py` | 4: те саме для розгалужених маршрутів — дерево, віяло, з поверненням | ~20 с |

Кількість подій і всі показники моделі відтворювані (`fun_rand.seed(1)`). Час обчислення залежить
від комп'ютера та його завантаження, тому при повторному запуску секунди трохи відрізняються від
звіту, а показник степеня m і висновки — ні.

## Основні результати

* Кожна вимога породжує 1 + V подій (V — середня кількість СМО на її маршруті), а обробка однієї
  події займає a + b·N, бо алгоритм на кожному кроці проходить усі N + 2 елементи.
  Тому складність O(ν·T·k) = O(T / tC · (1 + V) · N).
* Послідовна мережа: V = N, складність O(N²) — при подвоєнні N час зростає майже вчетверо.
* Розгалуження без повернень зменшують V: дерево — V ≈ log₂N, O(N·log N); віяло — V = 1, O(N).
  Повернення збільшують V до N / (1 − p) і час — у 1 / (1 − p) разів, складність лишається O(N²).
