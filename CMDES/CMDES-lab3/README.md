# Комп'ютерний практикум №3 — «Побудова імітаційної моделі системи з використанням формалізму моделі масового обслуговування»

Python 3.12, лише стандартна бібліотека (залежностей немає).

## Універсальний алгоритм

| Файл | Зміст |
|---|---|
| `element.py` | `Customer` — вимога (тип, момент надходження); `Element` — затримка і вибір маршруту за ймовірністю, за пріоритетом або за довільним правилом |
| `create.py` | `Create` — джерело вимог заданого типу |
| `process.py` | `Process` — довільна кількість пристроїв, обмежена черга, пріоритет у черзі, статистика |
| `dispose.py` | `Dispose` — вихід із моделі, час перебування вимог у системі за типами |
| `model.py` | `Model` — алгоритм імітації за принципом найближчої події |
| `fun_rand.py` | генератори exp, unif, norm, erlang |
| `theory.py` | аналітичні формули M/M/c/K для перевірки |

## Завдання

Кожний скрипт запускається окремо, без аргументів:

| Скрипт | Завдання |
|---|---|
| `task1_universal.py` | 1: перевірка універсального алгоритму — маршрут за пріоритетом і за ймовірністю, порівняння з M/M/2/4 |
| `task2_bank.py` | 2: банк для автомобілістів — дві каси, вибір коротшої смуги, зміна смуги |
| `task3_hospital.py` | 3: приймальне відділення лікарні — три типи хворих, супровідні, лабораторія |

Результати відтворювані: у кожному прогоні генератор ініціалізується `fun_rand.seed(1)`,
тому вивід програм збігається з наведеним у звіті (`report/Звіт_КП3.docx`).
