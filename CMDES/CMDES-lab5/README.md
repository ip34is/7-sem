# Комп'ютерний практикум №5 — «Формалізація дискретно-подійних систем стохастичною мережею Петрі»

Мережі Петрі побудовано в редакторі **PetriObjModelPaint** (І. В. Стеценко,
[github.com/StetsenkoInna/PetriObjModelPaint](https://github.com/StetsenkoInna/PetriObjModelPaint), реліз 2.8.2),
а експерименти виконано на Java алгоритмом імітації цієї ж бібліотеки (`PetriSim`, `PetriObjModel`).

## Файли

| Шлях | Зміст |
|---|---|
| `nets/*.png` | зображення мереж Петрі з редактора |
| `nets/*.pnml` | мережі у форматі PNML — відкриваються в редакторі через File → Open |
| `nets/*.txt` | мережі у вигляді Java-методу (Save net as method) |
| `src/Nets.java` | ті самі методи; параметри експериментів винесено в аргументи |
| `src/Sim.java` | запуск мережі класом `PetriObjModel`, доступ до позицій і переходів за назвою |
| `src/Task1Conveyor.java` | 1: конвеєр із п'яти пристроїв |
| `src/Task2Robots.java` | 2: гнучка виробнича система, два способи закріплення роботів |
| `src/Task3Minibus.java` | 3: два мікроавтобуси, вибір кількості місць n і виручка |
| `src/Task4Fridges.java` | 4: управління запасами холодильників |
| `run.bat` | запуск задачі |
| `report/` | звіт `Звіт_КП5.docx` / `.pdf` |

## Запуск

Потрібні Java 23+ і редактор PetriObjModelPaint (його jar використовується як бібліотека).
`run.bat` шукає його в `%USERPROFILE%\Downloads\PetriObjModelPaint\app\petri-swing-ui-windows.jar`;
інший шлях можна задати змінною `PETRI_JAR`.

```bash
run.bat Task1Conveyor
```

Мережу можна відкрити в редакторі (`nets/*.pnml`), запустити з анімацією і подивитися статистику.

Генератор випадкових чисел бібліотеки (`Math.random`) не ініціалізується фіксованим значенням, тому
числа від запуску до запуску трохи відрізняються від звіту; висновки — ні.

## Основні результати

* **Конвеєр**: завантаження пристроїв 0,88 / 0,86 / 0,81 / 0,76 / 0,68, у середньому зайнято 3,99
  пристрою (λ·tобр = 4), деталь перебуває в системі ≈ 9,3 хв.
* **Роботи**: при надходженні раз на 40 с система перевантажена; пропускна здатність ≈ 76 деталей/год,
  якщо за кожним шляхом закріплено свого робота, і ≈ 72 деталі/год, якщо до деталі їде найближчий.
* **Маршрутки**: найменше очікування в черзі — при n = 25 (≈ 28 хв).
* **Холодильники**: середній запас ≈ 28,8, середній час між продажами, що не відбулися, ≈ 2,3 тижня.
