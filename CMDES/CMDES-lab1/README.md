# Комп'ютерний практикум №1 — «Перевірка генератора випадкових чисел на відповідність закону розподілу»

Python 3.12 + NumPy / SciPy / Matplotlib. Залежності: `pip install -r requirements.txt`
(у проєкті вже є готове середовище `.venv`).

| Файл | Зміст |
|---|---|
| `stats_utils.py` | оцінки μ~, σ²~, критерій згоди χ² з об'єднанням інтервалів, гістограма |
| `task1_exponential.py` | завдання 1: генератор x = −ln(ξ)/λ, перевірка на експоненційний закон при λ = 0.5; 1; 2; 5; 10 |
| `task1_lcg.py` | завдання 2: конгруентний генератор z(i+1) = a·z(i) mod c при 6 наборах (a, c), період, χ², пари/трійки |
| `task2_sort_timing.py` | завдання 3: затримка сортування 10⁶ об'єктів, ідентифікація закону, генератори-імітатори, точність |
| `output/` | графіки та виміряні дані `sort_times.csv` |
| `report/` | звіт `Звіт_КП1.docx` / `.pdf` |

## Запуск

Кожне завдання запускається окремо, без аргументів:

```bash
python task1_exponential.py
```

```bash
python task1_lcg.py
```

```bash
python task2_sort_timing.py
```

Завдання 3 аналізує збережені вимірювання `output/sort_times.csv` (результати збігаються зі звітом).
Щоб переміряти заново (500 запусків, ~8 хв), видаліть або перейменуйте цей файл і запустіть скрипт.

## Основні результати

* **Завдання 1.** При всіх λ гіпотеза про експоненційний закон приймається за χ²
  (напр. λ = 1: χ² = 18.85 < χ²кр = 21.03).
* **Завдання 2.** При a = 5¹³, c = 2³¹ генератор відповідає U(0;1) (χ² = 21.69 < 30.14), період > 2·10⁶.
  Малий модуль (c = 2⁸) і парне a (2¹⁰) дають короткий період / виродження — χ² відхиляє гіпотезу.
  RANDU (a = 65539) проходить χ², але його трійки лежать на 15 площинах (див. `task1_lcg_3_pairs.png`).
* **Завдання 3.** μ~ = 544.8 мс, σ~ = 57.3 мс, асиметрія 2.29; ряд нестаціонарний (див. `task2_series.png`),
  тому жоден стандартний закон не прийнято, найближчий — логнормальний зі зсувом.
  Табличний генератор відтворює затримку найточніше (χ² однорідності 0.19 < 16.92),
  логнормальний — лише середнє та σ.
